1. WHAT THIS IS
   This is an unofficial, noncommercial fan port made by T.M. DEVELOPMENTS. It lets the 1998
   game Rugrats Adventure Game run on modern 64-bit (x64) Windows. It is a new program that plays
   the original game's files. It contains NO game content: no art, animation, video, voices,
   music, scripts or text from the original game.

2. YOU MUST OWN THE ORIGINAL
   To make our lawyers happy, you may only use this port with an original, lawfully obtained
   copy of the Rugrats Adventure Game CD-ROM that you own. Setup copies the game files from
   that disc to your computer for your personal use, and the game runs from that copy. Do
   not use this port with copies you do not own, and do not distribute the game's files.
